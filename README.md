# classboard

교사 개인의 Cloudflare 무료 계정에 직접 설치해서 쓰는 교실 전자칠판입니다. 설치 하나가 교사 한 명, 학급 하나입니다.

> **지금은 개발 중입니다.** 이 저장소에 있는 것은 **검증용 시험판**입니다. 학교망 접속, 판서 지연, Cloudflare 무료 한도를 확인하는 용도이고, 실제 수업용 칠판은 아직 들어 있지 않습니다.

## 판 구성

| | 기본판 | 저장판 | 서버판 |
| --- | --- | --- | --- |
| 설치 위치 | 개인 Cloudflare 무료 계정 | 개인 Cloudflare 무료 계정 + R2 | 개인 서버(Docker) |
| 카드 등록 | 필요 없음 | R2를 켤 때 요구될 수 있음 | 필요 없음 |
| 자료 저장 | 화면용 이미지만(원본은 교사 PC) | 원본 PDF·사진·동영상까지 | 서버 디스크 |
| 상태 | 개발 중 | 개발 중 | 곧 릴리스 |

두 판 모두 판서와 동기화, 전자칠판 등록·PIN, 수학 도구, 학급 도구(뽑기·모둠·자리·타이머), 교시별 기록, 학생 호출(칠판에 직접 판서)을 지원합니다. 학생은 계정 없이 학급 코드와 번호로 들어오고, 서버에는 번호만 저장합니다.

### 서버판 (곧 릴리스)

학교나 개인이 운영하는 서버에 Docker로 설치하는 전체 기능판입니다. Cloudflare 무료 한도의 영향을 받지 않고, 자료는 서버 디스크에 저장합니다.

- 기본판·저장판의 모든 기능
- 합반 수업: 여러 반 전자칠판에 같은 판서를 동시 송출하고, 진행 교사의 음성·웹캠을 함께 보냄
- 원격 수업: 집에 있는 학생이 수업 화면을 보고 호출에 참여
- 여러 교사·여러 학급을 한 서버에서 운영
- 동영상·PDF를 서버에 올려 모든 기기에서 사용
- 설치 조건: Docker가 도는 서버와, 외부 접속용 Cloudflare Tunnel 또는 공인 IP

## 검증용 시험판 설치

**반드시 시험용 Cloudflare 계정에 설치하세요.** 아래 4번 시험은 그 계정의 무료 한도를 일부러 넘깁니다.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/pooha3240/classboard)

1. 위 버튼을 누르고 Cloudflare 계정으로 로그인합니다. GitHub 계정 연결을 요구하면 연결합니다(저장소가 내 계정에 복사됩니다).
2. 배포가 끝나면 `https://classboard.<계정>.workers.dev` 주소가 생깁니다.

GitHub 계정 없이 설치하는 '설치 도우미'는 기본판과 함께 나옵니다.

## 시험 방법

시험판 페이지를 열면 네 가지 시험이 있습니다.

1. **연결**: 학교 전자칠판에서 페이지가 열리고 '연결됨'이 뜨는지 봅니다. 학교망에서 `workers.dev`와 WebSocket이 막히지 않았는지 확인하는 시험입니다.
2. **지연 측정**: 왕복 지연(ms)을 20회 잽니다.
3. **판서 동기화**: 전자칠판과 교사 PC(또는 태블릿)에서 같은 페이지를 열고 그려 봅니다. 다른 기기에 바로 나타나야 합니다.
4. **무료 한도 시험**: Durable Object로 보내는 WebSocket 메시지 20개를 1건으로 세는 계산이 무료 플랜에도 적용되는지 확인합니다. 한국 시간 오전 9시(UTC 0시) 이후에 15만 개를 보냅니다.
   - 10만 개 근처에서 끊기고 '새 연결 시험'도 실패하면 → 적용되지 않음
   - 15만 개를 다 보내고 '새 연결 시험'도 성공하면 → 적용됨

## 개발

