# classboard

교사 개인의 Cloudflare 무료 계정에 직접 설치해서 쓰는 교실 전자칠판입니다. 설치 하나가 교사 한 명, 학급 하나입니다.

> **지금은 개발 중입니다(기본판·저장판 0.12.0).** 판서·페이지·수업(교시) 기록·판서 기록 보기·교시 시각·시간표 설정·진도표·차시 자료·수학 도구·학급 도구(번호 뽑기 등)·학생 호출(칠판에 풀기)·전자칠판 등록·PIN·사진·PDF 자료가 동작합니다.

## 판 구성

| | 기본판 | 저장판 | 서버판 |
| --- | --- | --- | --- |
| 설치 위치 | 개인 Cloudflare 무료 계정 | 개인 Cloudflare 무료 계정 + R2 | 개인 서버(Docker) |
| 카드 등록 | 필요 없음 | R2를 켤 때 요구될 수 있음 | 필요 없음 |
| 자료 저장 | 화면용 이미지만(원본은 교사 PC) | 원본 PDF·사진·동영상까지 | 서버 디스크 |
| 상태 | 개발 중 | 개발 중 | 곧 릴리스 |

두 판 모두 판서와 동기화, 전자칠판 등록·PIN, 수학 도구, 학급 도구(뽑기·모둠·자리·타이머), 교시별 기록, 학생 호출(칠판에 직접 판서)을 지원합니다. 학생은 계정 없이 학급 코드와 번호로 들어오고, 서버에는 번호만 저장합니다.

### 서버판 (곧 릴리스)

학교나 개인이 운영하는 서버에 Docker로 설치하는 전체 기능판입니다. Cloudflare 무료 한도의 영향을 받지 않고, 자료는 서버 디스크에 저장합니다.

- 기본판·저장판의 모든 기능
- 합반 수업: 여러 반 전자칠판에 같은 판서를 동시 송출하고, 진행 교사의 음성·웹캠을 함께 보냄
- 원격 수업: 집에 있는 학생이 수업 화면을 보고 호출에 참여
- 여러 교사·여러 학급을 한 서버에서 운영
- 동영상·PDF를 서버에 올려 모든 기기에서 사용
- 설치 조건: Docker가 도는 서버와, 외부 접속용 Cloudflare Tunnel 또는 공인 IP

## 전자칠판 도우미(선택)

칠판에 실시간으로 띄운 다른 탭(아이스크림 등)을 칠판 화면에서 눌러 조작하게 해 주는 크롬 확장. 칠판 설정 화면에서 받으면 그 칠판 주소가 채워진 zip 을 줍니다(`/helper.zip`, 원본은 `web/helper/ext/`).

## 판

- **기본판**: 카드 등록 없이 무료. 자료 700MB, 판서 재생 60일, 백업 내려받기·되살리기.
- **저장판**: Cloudflare R2(무료 10GB, 켤 때 카드 또는 PayPal 등록 필요)를 더해 자료 6GB·차시 자료 2GB, 판서 기록(재생 포함) 계속 보관. R2 사용은 8GB 에서 막아 무료 범위를 넘지 않게 했습니다. 설정 파일은 `wrangler.storage.jsonc`.
- **서버판**: 곧 릴리스(개인 서버에서 합반·원격 수업까지).

## 설치

**[설치 안내 보기 → docs/INSTALL.md](docs/INSTALL.md)**

- **GitHub 계정 없이 (Windows)**: [zip 파일](https://github.com/pooha3240/classboard/archive/refs/heads/main.zip)을 받아 압축을 풀고 `install-windows.bat` 을 실행합니다. Cloudflare 로그인·배포·설치 키 만들기까지 도우미가 합니다.
- **GitHub 계정으로**: 이 저장소를 Fork 한 뒤 Cloudflare 의 Workers & Pages → Import a repository 로 연결하고, Secret `SETUP_KEY` 를 넣습니다. 업데이트는 Sync fork 한 번입니다.

설치 뒤 주소를 열어 처음 설정(학급·교사 계정) → 교시 시각 → 전자칠판 등록 순서로 하면 됩니다.

다른 기기의 판서는 Cloudflare 경로에 따라 0.3초 정도 늦게 보일 수 있습니다. 내가 그리는 판서는 바로 그려집니다.

### 검증 페이지

`/probe.html` 에서 학교망 접속, 지연, 무료 한도(20:1) 시험을 할 수 있습니다. 4번 한도 시험은 그 계정의 무료 한도를 일부러 넘기므로 **시험용 계정에서만** 하세요.

## 전자칠판 등록

1. 교실 전자칠판에서 한 번만 교사 아이디로 로그인하고 **전자칠판**을 고릅니다.
2. **이 기기를 전자칠판으로 등록**에 체크된 상태에서 PIN(숫자 4~6자리)을 정하고 학급을 누릅니다.
3. 이후 그 전자칠판은 로그인 없이 바로 켜집니다. 교사 로그인은 기기에 남지 않습니다.
4. 지난 기록 열기·등록 해제는 PIN 이 필요합니다(5번 틀리면 5분 잠김). PIN 을 바꾸려면 교사 PC 에서 로그인해 전자칠판을 다시 등록하면서 새 PIN 을 넣습니다.
5. 전자칠판을 바꾸거나 잃어버렸으면 교사 PC 메뉴 → **등록된 전자칠판**에서 해제합니다.

비밀번호를 잊어 설치 키로 다시 설정하면, 보안을 위해 모든 기기(교사 기기·전자칠판·학생)가 로그아웃되고 PIN 도 지워집니다. 전자칠판은 다시 등록해야 합니다.

## 교시 시각·시간표 (설치 후 처음 할 일)

- 메뉴 → **교시·시간표 설정**에서 우리 학교 종 시각을 넣고 저장하세요. 기본값인 동안은 칠판에 알림이 뜹니다.
- **빠르게 채우기**: 1교시 시작, 수업·쉬는 시간 길이, 점심 위치만 넣으면 표가 채워지고, 다른 시각만 고쳐 저장하면 됩니다.
- 판서는 교시마다 따로 기록되고, 교시가 바뀌면 칠판이 새 수업으로 넘어갑니다(직전 수업 이어 쓰기 가능).
- 학급 시간표(선택)에 과목을 적어 두면 칠판 위쪽과 판서 기록에 과목이 붙습니다.

## 진도표·차시 자료

- 메뉴 → **주간 진도·차시 자료** → **나이스 파일 올리기**: 나이스 '교육과정 연간지도계획'(엑셀)을 올리면 날짜·교시마다 과목과 차시가 붙습니다. '학기별 시간표 조회'(PDF)도 올리면 교시가 정확해집니다(선택). 파일은 이 기기 브라우저에서 읽고 내용만 보냅니다.
- 주간 표에서 칸을 눌러 **다른 시간과 바꾸기(교체)**, **과목 바꾸기**, **이 시간 없음(행사)**, **이 차시 한 번 더**, **건너뛰기**를 하면 그 과목의 뒤 차시가 저절로 밀리고 당겨집니다. 진도표를 다시 올려도 이 조정은 다시 적용됩니다.
- 차시마다 사진·PDF·유튜브·웹 주소를 미리 붙여 두면, 그 시간이 되어 새 수업이 시작될 때 전자칠판이 자료를 페이지로 깔아 두고, 칠판 위쪽에 과목과 차시가 보입니다. 칠판의 **자료** 창에도 '이 시간 차시 자료'가 나옵니다.
- **나이스 시간표 자동 받기(선택)**: 교시·시간표 설정에서 나이스 교육정보 개방 포털 인증키를 넣고 학교를 고르면, 매일 새벽 학교 시간표(교체·행사 반영)를 받아 진도를 다시 맞춥니다. 진도표를 올릴 때도 바로 받아 교시를 맞춥니다. 넣지 않아도 다른 기능은 그대로입니다.
- 차시에 붙인 사진·PDF 는 자동으로 지워지지 않으며 모두 합쳐 300MB 까지입니다. 한 학기 전부를 미리 붙이기보다 한두 주 앞을 준비하는 데 맞춘 크기입니다(더 큰 공간은 저장판).

## 판서 기록

- 메뉴 → **판서 기록**: 날짜·교시별로 지난 판서를 보고, 쪽마다 쓴 순서대로 다시 재생하고, **PDF로 저장**(인쇄 창)할 수 있습니다. **이 판서로 이어서 수업**을 누르면 칠판에 다시 엽니다.
- 등록된 전자칠판에서는 PIN 이 필요합니다.
- 판서 재생용 동작 기록은 60일 동안 보관하고, 그 뒤에는 완성된 판서만 남깁니다(저장 공간 절약).
- 전체 저장 공간은 950MB 입니다(무료 플랜 한도 1GB). 판서 기록이 늘면 자료 보관 한도가 그만큼 줄어듭니다. 기록 화면 아래에 사용량이 보입니다. 필요 없는 기록은 지울 수 있습니다.

## 사진·PDF 자료

- 칠판의 **자료 → 사진·PDF 불러오기**(교사 PC 는 끌어다 놓기·붙여넣기도 됨). 고른 쪽을 새 페이지로 넣거나 지금 페이지 배경으로 깝니다.
- 변환은 올리는 기기의 브라우저가 합니다(PDF 는 pdf.js 로 쪽마다 그림으로). 서버에는 그림만 저장되어 R2 가 필요 없습니다.
- PDF 는 60쪽까지. 한글·PowerPoint·Word 파일은 PDF 로 저장해서 올리세요. 같은 파일을 다시 올리면 전에 바꾼 것을 그대로 씁니다.
- 자료는 700MB 까지(판서 기록이 많으면 그보다 적게) 쓰고, 넘치면 오래 안 쓴 자료부터 지웁니다. 지운 자료를 깔았던 지난 페이지는 배경이 비어 보입니다.
- 동영상 파일은 기본판에서 올릴 수 없습니다. 유튜브(일부 공개)에 올려 주소로 띄우세요.

## 학생 참여

1. 칠판의 **학급 도구 → 호출** 탭에 QR 코드와 학급 코드가 보입니다. **크게 보기**를 누르면 칠판 전체에 띄웁니다.
2. 학생은 태블릿으로 QR을 찍고(또는 `주소/s`에서 숫자 6자리 코드 입력) 자기 번호를 고릅니다. 한 번 들어오면 그 태블릿은 12시간 동안 기억합니다.
3. 번호를 고르고 **칠판에 풀기**를 누르면 그 학생 태블릿에 지금 칠판이 보이고, 학생이 쓴 것이 칠판에 바로 나옵니다. 학생은 자기가 쓴 것만 지울 수 있습니다.
4. 코드가 새어 나갔으면 **코드 바꾸기**를 누르세요. 들어와 있던 학생은 모두 나가고 새 QR로 다시 들어와야 합니다.
