# classboard 설치 안내 (기본판·저장판)

교사 한 명이 자기 Cloudflare 무료 계정에 학급 전자칠판을 설치하는 방법입니다. 처음 설치는 20~30분쯤 걸리고, 비용과 카드 등록은 필요 없습니다.

설치가 끝나면 `https://classboard.<내가 정한 이름>.workers.dev` 주소가 생기고, 교사 PC·태블릿·전자칠판·학생 태블릿이 모두 이 주소로 들어옵니다.

## 0-1. 판 고르기

| | **기본판** | **저장판** |
| --- | --- | --- |
| 카드 등록 | 필요 없음 | 필요(Cloudflare R2 를 켤 때 카드 또는 PayPal. 무료 10GB 안에서는 청구 없음) |
| 사진·PDF 자료 | 700MB | 6GB |
| 차시에 붙이는 자료 | 300MB | 2GB |
| 판서 재생 기록 | 60일(그 뒤 완성된 판서만) | 계속 보관(60일 지나면 R2 로 옮김) |
| 백업 내려받기·되살리기 | 있음 | 있음 |

저장판은 R2 사용을 8GB 에서 막아 무료 범위를 넘지 않게 했습니다. 기본판으로 쓰다가 저장판으로 바꿔도 판서·설정은 그대로입니다(같은 방법으로 다시 설치하면서 저장판을 고르면 됨).

**저장판을 쓰려면 먼저 R2 켜기**: Cloudflare 대시보드 → 왼쪽 **R2 Object Storage** → 안내에 따라 결제 수단(카드 또는 PayPal)을 등록하고 R2 를 켭니다. 버킷은 만들지 않아도 됩니다(설치할 때 자동으로 만들어짐).

## 0-2. 설치 방법 고르기

| | **방법 1. 설치 도우미 (GitHub 계정 없음)** | **방법 2. GitHub 계정으로** |
| --- | --- | --- |
| 필요한 것 | Windows 10·11 PC 한 대 | GitHub 계정, 브라우저 |
| 설치 | 파일을 받아 `install-windows.bat` 실행 → 설치 창에 정보 입력 | 저장소를 내 계정에 Fork 한 뒤 Cloudflare 에 연결 |
| 업데이트 | 새 파일을 받아 다시 실행 | GitHub 에서 **Sync fork** 한 번 (자동으로 새로 배포) |
| 추천 | 대부분의 선생님 | GitHub 를 써 본 선생님 |

어느 방법이든 **1단계 Cloudflare 가입**은 같습니다. 방법 1은 '처음 설정'까지 도우미가 해 주고, 방법 2는 **4단계 처음 설정**을 직접 합니다.

## 1. Cloudflare 가입 (공통)

1. <https://dash.cloudflare.com/sign-up> 에서 이메일과 비밀번호로 가입합니다.
2. 받은 메일의 인증 링크를 누릅니다.
3. 가입 뒤 나오는 요금제·도메인 안내는 건너뛰어도 됩니다. **무료(Free)** 그대로 씁니다. 도메인을 살 필요도 없습니다.

> 학교 공용 메일보다 오래 쓸 개인 메일을 권합니다. 학교를 옮겨도 칠판과 기록을 그대로 가져갑니다.

## 2. 방법 1: 설치 도우미 (GitHub 계정 없음, Windows)

1. **파일 받기**: <https://github.com/pooha3240/classboard/archive/refs/heads/main.zip>
   (GitHub 로그인 없이 바로 받아집니다.)
2. 받은 `classboard-main.zip` 을 마우스 오른쪽 버튼 → **압축 풀기**. 바탕화면처럼 찾기 쉬운 곳에 풉니다.
3. 풀린 폴더 안의 **`install-windows.bat`** 을 두 번 누릅니다.
   - 'Windows의 PC 보호' 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
4. **설치 창**이 열립니다. 아래를 넣고 **[설치 시작]** 을 누릅니다.
   - **판**: 기본판 또는 저장판(저장판은 R2 를 먼저 켜야 함, 0-1 참고)
   - **주소 이름**: 칠판 주소 `https://classboard.<이름>.workers.dev` 에 쓸 이름. 영어 소문자·숫자·`-` 만 씁니다(예: `ulsan-kim5`). 바꾸기 어려우니 짧고 오래 쓸 이름으로 정하세요.
   - **학급**: 학년·반·학생 수
   - **교사 이름·아이디·비밀번호**: 칠판에 로그인할 때 씁니다(비밀번호 8자 이상, PC 에 저장하지 않음).
5. 그다음은 도우미가 혼자 진행합니다. 손이 가는 곳은 한 번뿐입니다.
   1. **설치 도구 준비**: Node.js 와 설치 도구를 내 사용자 폴더에만 받습니다(관리자 권한 필요 없음, 처음 1~3분).
   2. **Cloudflare 로그인**: 브라우저가 열리면 1단계에서 만든 계정으로 로그인하고 **Allow(허용)** 를 누릅니다. 브라우저가 안 열리면 설치 창의 파란 글씨를 누르세요.
   3. **계정과 칠판 주소**: 계정이 여러 개면 고르라고 묻습니다. 주소 이름을 누가 이미 쓰고 있으면 다른 이름을 묻습니다.
   4. **칠판 올리기** → **설치 키 만들기** → **주소가 열릴 때까지 기다리기**(새 주소는 2~5분 걸릴 수 있음) → **학급·교사 정보 넣기**
6. **설치가 끝났습니다** 화면에 칠판 주소가 나옵니다. **[칠판 열기]** 로 들어가 방금 정한 아이디·비밀번호로 로그인합니다. 웹의 '처음 설정'은 도우미가 이미 했으니, 4단계의 **2번(교시 시각)** 부터 하면 됩니다.
   - 설치 키는 바탕화면 `classboard-설치정보.txt` 에 저장됩니다. 비밀번호를 잊었을 때만 쓰는 열쇠이니 안전한 곳에 옮겨 두세요.
   - 새 주소가 늦게 열려 '올리기는 끝났습니다'가 나오면, 몇 분 뒤 [칠판 열기] 로 '처음 설정' 화면에서 설치 키와 학급·교사 정보를 넣으면 됩니다.

설치 창의 **[자세히 보기]** 는 진행 기록을 보여 주고, 문제가 생기면 **[기록 파일 열기]** 로 기록을 볼 수 있습니다(`%LOCALAPPDATA%\classboard\install-log.txt`). 설치 창이 열리지 않는 PC 에서는 예전처럼 검은 글자 화면 도우미가 대신 열립니다.

> **학교망에서 막히면**: 학교 보안 프로그램이 Node.js·Cloudflare 접속을 막는 경우가 있습니다. 집이나 휴대폰 핫스팟에서 설치하세요. 설치는 한 번만 하면 되고, 교실에서 쓰는 데는 상관없습니다.

### macOS 에서 설치하려면

터미널에서 압축을 푼 폴더로 가서 차례로 실행합니다(Node.js 22 이상 필요, <https://nodejs.org>).

```sh
npm ci
npx wrangler login
npx wrangler deploy                    # 저장판: npx wrangler deploy -c wrangler.storage.jsonc
npx wrangler secret put SETUP_KEY     # 설치 키를 직접 정해 입력(아무도 모르는 긴 문자열)
```

`deploy` 가 알려 주는 `https://…workers.dev` 주소를 열고 4단계로 갑니다.

## 3. 방법 2: GitHub 계정으로

다른 프로그램에서 흔히 보는 **Deploy to Cloudflare** 버튼은 저장소를 내 계정에 '복사'만 해서 나중에 새 버전을 받아 오기 어렵습니다. 그래서 classboard 는 **Fork 한 뒤 연결**하는 방법을 씁니다.

1. <https://github.com/pooha3240/classboard> 오른쪽 위 **Fork** → **Create fork**.
2. Cloudflare 대시보드 → **Workers & Pages** → **Create** → **Import a repository**(Git 저장소 연결) → GitHub 연결을 허용하고 방금 만든 `classboard` 저장소를 고릅니다.
3. **저장판**이면 Deploy command 를 `npx wrangler deploy -c wrangler.storage.jsonc` 로 바꿉니다(기본판은 그대로). **Deploy**. 1~2분 뒤 배포가 끝나고 `https://classboard.<계정 이름>.workers.dev` 주소가 나옵니다.
   - 처음이면 workers.dev 주소 이름을 정하라고 나올 수 있습니다.
4. **설치 키 넣기**: 그 Worker 화면 → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret** (꼭 Secret 으로)
   - Variable name: `SETUP_KEY`
   - Value: 아무도 모르는 긴 문자열(예: 단어 서너 개와 숫자). 따로 적어 둡니다.
   - **Deploy** 를 누릅니다.
5. 주소를 열고 4단계로 갑니다.

## 4. 처음 설정 (공통)

1. **처음 설정**: 주소(`…/login`)를 열면 '처음 설정' 화면이 나옵니다. 설치 키, 학년·반·학생 수, 이름, 아이디·비밀번호(8자 이상)를 넣습니다.
   - "SETUP_KEY 비밀값이 아직 없습니다"가 나오면 2·3단계의 설치 키 넣기를 다시 확인하세요.
2. **교시 시각**: 칠판이 열리면 메뉴(⋯) → **교시·시간표 설정**에서 우리 학교 종 시각을 넣고 저장합니다. **빠르게 채우기**로 1교시 시작·수업 길이·쉬는 시간·점심만 넣으면 표가 채워집니다. 이걸 해야 판서가 교시별로 바르게 기록됩니다.
3. **전자칠판 등록**: 교실 전자칠판의 브라우저로 같은 주소를 열어 로그인 → 이 기기 **전자칠판** → **이 기기를 전자칠판으로 등록**에 체크하고 PIN(숫자 4~6자리)을 정한 뒤 학급을 누릅니다. 이후 전자칠판은 로그인 없이 바로 켜집니다. 브라우저의 '홈 화면에 추가'나 즐겨찾기로 바로 열 수 있게 해 두면 편합니다.
4. **교사 PC·태블릿**: 같은 주소로 로그인하고 이 기기 종류를 고르면 같은 칠판이 보입니다.
5. **진도표(선택)**: 메뉴 → 주간 진도·차시 자료 → 나이스 파일 올리기에서 '교육과정 연간지도계획' 엑셀(필요하면 '학기별 시간표 조회' PDF 도)을 올리면 수업마다 과목·차시가 붙습니다. 학교 시간표 교체·행사까지 매일 자동으로 반영하려면 교시·시간표 설정의 **나이스 시간표 자동 받기**에 인증키(<https://open.neis.go.kr> 에서 무료 신청)를 넣고 학교를 고르세요.
6. **학생 참여**: 칠판의 학급 도구 → **호출** 탭에 QR 코드와 숫자 6자리 학급 코드가 있습니다. 학생은 태블릿으로 QR 을 찍고 자기 번호를 고르면 됩니다. 학생 이름은 저장하지 않습니다.

## 5. 업데이트

판서·자료·설정은 Cloudflare 계정에 그대로 남고, 프로그램만 바뀝니다. 메뉴 → 교시·시간표 설정 화면 아래에서 지금 판과 최신 판을 볼 수 있습니다.

- **방법 1(설치 도우미)**: 2단계처럼 새 zip 을 받아 압축을 풀고 `install-windows.bat` 을 다시 실행합니다. 이 PC 에서 설치했으면 설치 창이 **업데이트** 화면으로 열리니 [업데이트] 만 누르면 됩니다. 다른 PC 에서 설치했으면 창 아래의 '이미 설치한 칠판이면 여기를 눌러 업데이트하기'를 누릅니다.
- **방법 2(GitHub)**: 내 GitHub 의 classboard 저장소 → **Sync fork** → **Update branch**. Cloudflare 가 자동으로 새로 배포합니다(2~3분).

업데이트 뒤 칠판에 '새 버전' 알림이 뜨면 새로 고침하세요.

## 6. 문제 해결

| 증상 | 해결 |
| --- | --- |
| 도우미가 "Node.js 를 받지 못했습니다" | 학교망 차단. 집이나 핫스팟에서 다시 실행 |
| 도우미가 "설치 도구를 받지 못했습니다" | 위와 같음. 회사·학교 보안 프로그램(SSL 검사)이 있으면 꺼지는 환경에서 실행 |
| 로그인 창에서 Allow 를 눌렀는데 진행이 안 됨 | 설치 창에서 [취소] → [다시 시도](로그인은 기억됨) |
| 주소 이름을 다시 묻는 창이 뜸 | 누가 이미 쓰는 이름. 뒤에 숫자를 붙이는 등 다른 이름을 넣기 |
| 다른 Cloudflare 계정에 올리고 싶음 | 설치 창의 '다른 Cloudflare 계정으로 로그인하기'를 체크하고 설치 |
| 설치 창이 뜨지 않음 | 보안 프로그램이 막았을 수 있음. 검은 글자 화면 도우미가 대신 열리면 그 안내를 따르기 |
| 처음 설정에서 "설치 키가 맞지 않습니다" | 바탕화면 메모의 키를 정확히(하이픈 포함) 넣기. 방법 2는 Secret 값 확인 |
| 처음 설정에서 "SETUP_KEY 비밀값이 아직 없습니다" | 방법 2의 4번(Secret)을 했는지, Type 이 Secret 인지 확인 |
| 비밀번호를 잊음 | 로그인 화면 아래 '비밀번호를 잊었을 때' → 설치 키로 다시 설정(모든 기기가 로그아웃되고 전자칠판은 다시 등록) |
| 저장판 설치에서 올리기 실패 | R2 를 켰는지 확인(0-1의 'R2 켜기'). 켠 뒤 다시 실행 |
| 다른 기기 판서가 조금 늦게 보임 | Cloudflare 경로 때문에 0.3초 안팎 늦을 수 있습니다. 내가 그리는 판서는 바로 그려집니다 |

## 7. 무료 한도와 저장 공간

- Cloudflare 무료 계정 한도 안에서 한 학급이 하루 종일 쓰도록 만들었습니다. 카드 등록이 없으므로 한도를 넘어도 요금이 나가지 않고, 그날 남은 시간 동안 일부 기능이 멈출 수 있습니다(다음 날 오전 9시에 다시 채워짐).
- 기본판 저장 공간은 판서 기록과 자료를 합쳐 950MB 까지 씁니다. 저장판은 여기에 R2 8GB(자료 + 보관한 판서 기록)가 더해집니다. 판서 기록 화면 아래와 교시·시간표 설정의 저장판 칸에서 사용량을 볼 수 있습니다.
- 저장판은 카드가 등록된 계정이라 무료 범위를 넘으면 요금이 나갈 수 있지만, 프로그램이 R2 를 8GB 에서 막고 한 학급 수업의 요청 수는 무료 한도(월 100만·1,000만 회)에 한참 못 미칩니다.

## 7-1. 전자칠판 도우미 (선택)

아이스크림처럼 칠판 안에 띄울 수 없는 사이트를 '다른 탭 실시간으로 띄우기'로 띄운 뒤, 칠판 화면에서 손가락으로 눌러 조작하게 해 주는 크롬 확장입니다. 교시·시간표 설정 → **전자칠판 도우미**에서 받아 크롬·엣지·웨일에 '압축해제된 확장 프로그램'으로 깝니다(설정 화면에 순서가 있음). 받은 칠판 주소에서만 동작하므로, 칠판 주소를 바꾸면 다시 받습니다.

## 8. 백업과 옮기기

교시·시간표 설정 → **저장 공간과 백업**에서 백업 파일을 내려받고(서버 공간은 쓰지 않고 내 PC 에 저장. 크롬·엣지는 저장 위치를 먼저 골라 크기에 상관없이 바로 씀), 새로 설치한 곳에서 **백업에서 되살리기**로 옮깁니다. 교사 계정·학급 코드·전자칠판 등록·나이스 인증키는 백업에 들어가지 않으니 새 곳에서 다시 정합니다. 기본판은 판서 재생 기록이 60일만 남으므로, 오래 보관하려면 학기마다 백업을 내려받아 두세요. 저장판 백업을 기본판으로 되살리면 기본판 한도(자료 700MB)를 넘는 자료는 건너뜁니다.

## 9. 지우기

Cloudflare 대시보드 → Workers & Pages → classboard → Settings → **Delete**. 판서 기록과 자료가 모두 지워지고 되살릴 수 없습니다. 저장판은 R2 Object Storage 에서 classboard 버킷도 지웁니다.
